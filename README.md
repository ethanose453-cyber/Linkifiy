# Linkify.ma

منصة مغربية تربط **الأطر التربوية والإدارية** بـ**المؤسسات التعليمية الخاصة** القريبة منهم
(مدارس خاصة، مراكز لغات، مراكز تكوين، حضانات، ومؤسسات التعليم العالي الخاص).

> القيمة الأساسية: **المطابقة الجغرافية** — توصيل ملف الأستاذ للمؤسسات الأقرب لمكان سكناه.

---

## الوضع الحالي (MVP)

- **landing page** ثابتة (HTML/CSS/JS) فيها **فورم تسجيل مدمج** متعدد المراحل (6 خطوات).
- الفورm مربوط بـ **Google (Apps Script)** — بلا Tally:
  - الملفات (CV، شواهد، صورة) → **Google Drive**
  - البيانات + روابط الملفات → **Google Sheet**
  - **إشعار إيميل** مع كل تسجيل
- **مجاني تماماً للأساتذة.** الصورة الشخصية **اختيارية**.
- مناطق الانطلاق: **سلا** و**القنيطرة**.

## الملفات

| الملف | الوصف |
|------|--------|
| `index.html` | الصفحة + فورم التسجيل (RTL، عربي) |
| `styles.css` | التنسيقات (بدون framework) |
| `form.js` | منطق الفورم: المراحل، المنطق الشرطي، التحقق، الرفع |
| `apps-script/Code.gs` | الباكند على Google Apps Script |
| `SETUP.md` | **دليل ربط الفورم بـ Google (5 دقائق)** |

## التشغيل محلياً

```bash
python3 -m http.server 8000   # ثم http://localhost:8000
```

## ⚙️ الإعداد (مهم)

الفورم ماغاديش يسجّل حتى تربطو بـ Google. **اتبع [`SETUP.md`](SETUP.md)**:
تنشئ Sheet + مجلد Drive، تنشر Apps Script، وتلصق رابط الـ Web App فـ `form.js`
(المتغير `GOOGLE_SCRIPT_URL`).

## المنطق الشرطي (محفوظ من الفورم القديم)

- المدينة = «مدينة أخرى» → يظهر حقل اسم المدينة
- أعلى شهادة = «غير ذلك» → يظهر حقل اسم الشهادة
- «هل سبق لك العمل؟» = «لا (حديث التخرج)» → تختفي حقول الخبرة
- «مهارة أخرى» → يظهر حقل نصي

## قرارات المنتج (متفق عليها)

- ❌ بدون وعود "تحليل ذكي" / "مراسلة أوتوماتيكية" قبل توفّر الميزة فعلياً.
- ❌ بدون ذكر القطاع العمومي (التوظيف فيه عبر المباريات الوطنية).
- ❌ حُذف حقل **الحالة الاجتماعية** (خطر تمييز — مدوّنة الشغل المادة 9).
- ⚠️ حقول حسّاسة بقيت بطلب صاحب المشروع (السن، الجنس): يُنصح بمراجعتها قانونياً.
